# 🏥 Hospital Management System

A simple **Hospital Management System** developed using **Python** to manage basic hospital operations such as patient records, doctor information, appointments, and billing.

## 📌 Project Overview

The Hospital Management System is a Python-based application designed to simplify and organize hospital management activities. It helps maintain patient and doctor details and provides an easy way to manage appointments and other hospital records.

## 🚀 Technologies Used

* **Python**
* Python Functions
* Conditional Statements
* Loops
* Lists / Dictionaries
* File Handling
* Exception Handling

## ✨ Features

* 👤 Patient Registration
* 👨‍⚕️ Doctor Management
* 📅 Appointment Management
* 🔍 Search Patient Records
* 📋 View Patient Details
* 💰 Billing Management
* 🗑️ Update and Delete Records
* ⚠️ Exception Handling
* 💾 Data Storage

## 💻 How to Run

1. Install **Python** on your system.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the following command:

